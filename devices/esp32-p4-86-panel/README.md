# ESP32-P4-86-Panel-ETH-2RO (4")

4-inch 720x720 touchscreen panel that runs EspControl firmware for Home Assistant. Features 9 configurable buttons in a 3x3 grid, Ethernet support, an ESP32-C6 for Wi-Fi, audio output, a microphone for Voice Assistant, and two internal relays.

## Features

- **9 buttons** (3x3 grid) — control any Home Assistant device
- **Drag-and-drop ordering** — rearrange buttons from your browser
- **Voice Assistant** — built-in microphone and speaker
- **Ethernet and Wi-Fi** — use either for network connectivity
- **Two internal relays** — switch physical loads
- **Live clock** synced from NTP, with Home Assistant as a fallback
- **Screensaver** with adjustable idle timeout
- **Day/night brightness** — adjusts automatically based on sunrise and sunset
- **Over-the-air updates** — automatic or manual
